1) Different Fonts and Styles

This paragraph is styled using an ID selector. The heading above uses the Lobster font while this text uses Merriweather. We can make text italic, bold, underlined, uppercase, bigger or highlighted just by referring to a class in the body.

This line uses inline CSS (the style attribute) with the Comic Sans font.
